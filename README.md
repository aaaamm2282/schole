# سامانه انبار مدرسه (Schole)

وب‌اپلیکیشن مدیریت انبار کارگاه‌های مدرسه با رابط کاربری فارسی (راست‌به‌چپ).

## نقش‌ها

| نقش | کارها |
| --- | --- |
| **مدیر** | تعریف کاربران (سرپرست کارگاه، دبیر، نیروی خدماتی)، ساخت کارگاه‌ها و تعیین سرپرست هر کارگاه، دیدن همه کالاها و درخواست‌ها |
| **سرپرست کارگاه** | ثبت و ویرایش کالاهای کارگاه خودش، ورود/خروج موجودی، تحویل یا رد درخواست‌ها و دیدن گردش هر کالا |
| **دبیر** | دیدن کالاهای کارگاه‌ها، ثبت درخواست کالا، پیگیری یا لغو درخواست‌های خودش |
| **نیروی خدماتی** | مانند دبیر می‌تواند درخواست کالا ثبت کند |

هر تحویل، مقدار تحویلی را از موجودی کم می‌کند و در «گردش کالا» با نام تحویل‌گیرنده ثبت می‌شود.
سرپرست می‌تواند کمتر از مقدار درخواستی تحویل دهد؛ تحویل بیشتر از موجودی انبار ممکن نیست.

## اجرا

نیازمند Node.js نسخه ۲۲.۱۳ یا بالاتر (از SQLite داخلی Node استفاده می‌شود و نصب پایگاه داده جداگانه لازم نیست).

```bash
npm install
npm start          # http://localhost:3000
npm test
```

در اولین اجرا کاربر مدیر ساخته می‌شود:
نام کاربری `admin` و رمز `admin123`. بلافاصله پس از ورود از منوی «تغییر رمز عبور» آن را عوض کنید.
(یا پیش از اولین اجرا متغیرهای `ADMIN_USERNAME` و `ADMIN_PASSWORD` را تنظیم کنید.)

متغیرهای محیطی دیگر: `PORT` (پیش‌فرض ۳۰۰۰) و `DB_FILE` (پیش‌فرض `data/schole.db`).

## دیدن با گوشی

**در همان شبکه‌ی وای‌فای:** بعد از `npm start` آدرسی مثل `http://192.168.1.5:3000` در ترمینال چاپ می‌شود؛ همان را در مرورگر گوشی باز کنید.

**آنلاین (Railway، بدون کارت بانکی):** فایل `railway.json` آماده است. در railway.com با حساب GitHub وارد شوید،
New Project → Deploy from GitHub repo و این مخزن را انتخاب کنید. در Variables مقدار `ADMIN_PASSWORD` را بگذارید،
روی سرویس یک Volume با مسیر `/data` بسازید (پایگاه داده خودکار روی آن ذخیره می‌شود) و در Settings → Networking دکمه‌ی Generate Domain را بزنید.
حساب تازه ۵ دلار اعتبار آزمایشی ۳۰روزه می‌گیرد و بعد از آن ماهی ۱ دلار اعتبار رایگان دارد.

**آنلاین (Render):** فایل `render.yaml` آماده است. در render.com با حساب GitHub وارد شوید،
New → Blueprint را بزنید و این مخزن را انتخاب کنید. رمز مدیر به‌صورت تصادفی ساخته می‌شود و در بخش Environment سرویس دیده می‌شود.
نسخه‌ی رایگان دیسک ماندگار ندارد: با هر راه‌اندازی دوباره یا استقرار جدید، داده‌ها پاک می‌شوند و پس از ۱۵ دقیقه بی‌کاری سرویس می‌خوابد (اولین باز شدن بعدی حدود یک دقیقه طول می‌کشد).
برای نگه‌داشتن دائمی داده‌ها باید یک Persistent Disk (پولی) اضافه کنید و `DB_FILE` را روی مسیر آن بگذارید.

## ساختار

- `src/app.js` — API (Express)
- `src/db.js` — جدول‌های SQLite
- `public/` — رابط کاربری (HTML/CSS/JS بدون نیاز به build)؛ طراحی بر پایه‌ی سیستم طراحی ui-ux-pro-max (پالت سنگ‌لوحی و سبز، فونت وزیرمتن، آیکون‌های Lucide) با حالت تیره، انیمیشن‌های سبک و نمای کارتی برای موبایل
- `test/` — تست‌های API
